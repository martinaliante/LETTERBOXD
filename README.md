### Nombre del proyecto: Cinebox
### Integrantes: Martín Aliante, Ethan Araya, Mateo (...)
[Descripción]
Cinebox es una red social para compartir, puntuar y reseñar peliculas,
te permite llevar un registro personal de las peliculas que has visto o
tener una lista para ver mas tarde; tambien puedes seguir a otras personas
para saber que es lo que ven o recomiendan, asi como tu tambien puedes publicar
las peliculas que te gustaron.






## Requisitos: 
- Visual studio code
- Navegador 
- Extensión Live Server para visual studio (la de ritwick dey)

Instalación

1. Clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto en visual studio code.
3. Instalar la extensión Live Server si no está instalada.

Ejecución

1. Abrir el archivo `index.html`.
2. Hacer clic derecho sobre el archivo.
3. Seleccionar `Open with Live Server`.
4. La aplicación se abrirá en el navegador mediante una dirección local, por ejemplo:
   `http://127.0.0.1:5500/index.html`
